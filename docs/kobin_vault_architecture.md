# Kobin AI Vault Architecture

Kobin Vault is an AI-powered knowledge system designed to transform files into structured intelligence.

## Core Features
- AI labeling pipeline (post-extraction)
- Semantic embeddings for all files
- Async processing system
- Native file viewers (no iframe usage)
- AI Writer inside notes

## Pipeline
1. File upload
2. Text extraction
3. AI labeling
4. Embedding
5. Storage

## Design Principles
- Non-blocking UI
- Background processing
- High-quality labeling (delayed)
- Context-aware AI

## Future Scope
- Ask Vault (chat with documents)
- Source attribution
- Multi-file reasoning
